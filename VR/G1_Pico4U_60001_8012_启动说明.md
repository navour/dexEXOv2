# G1 + Pico4U 启动说明

本文档针对当前这台 G1 主机的实际部署状态，说明 60001 和 8012 两条链路分别做什么、如何启动、如何停止、如何访问。

当前机器已确认信息：
ssh unitree@192.168.3.85
密码：123
- G1 对外可访问 IP：192.168.3.85
- 头部相机页面端口：60001
- XR 页面端口：8012
- 头部相机当前为内置 RealSense 彩色流，配置为单目 640x480 30fps

## 1. 两个端口分别是什么

### 1.1 60001 是什么

60001 是头部相机的 WebRTC 预览页。

用途：

- 检查头部相机服务是否正常
- 让 Pico 浏览器先信任自签名证书
- 单独预览头部相机画面

特点：

- 这是相机预览页，不是正式的 XR 操作页面
- 当前配置下显示的是单目平面画面
- 访问后需要点击页面左上角 Start 才会开始显示图像

访问地址：

- https://192.168.3.85:60001

### 1.2 8012 是什么

8012 是正式的 XR 页面，也就是 Pico4U 进入 Virtual Reality 的入口。

用途：

- 让 Pico4U 进入 XR 页面
- 获取头部、手柄或手势数据
- 把头部图像送入 XR 视图

访问地址：

- https://192.168.3.85:8012/?ws=wss://192.168.3.85:8012

说明：

- 8012 依赖 60001 对应的 teleimager 图像服务已经先启动
- 如果 60001 没起来，8012 页面虽然可能能打开，但图像链路不会正常

## 3. 启动 60001

### 3.1 启动命令

```bash
source /home/unitree/.venvs/xrteleop/bin/activate
cd /home/unitree/xr_teleoperate/teleop/teleimager
teleimager-server
```

### 3.2 启动成功标志

终端里应看到类似信息：

```text
[OpenCVCamera: head_camera] initialized with 480x640 @ 30 FPS.
[Image Server] Image server has started, waiting for client connections...
[Image Server] head_camera is ready.
```

### 3.3 访问地址

```text
https://192.168.3.85:60001
```

### 3.4 如何停止

前台运行时：

```bash
Ctrl+C
```

后台运行时：

```bash
pkill -f teleimager-server
```

### 3.5 60001 的当前配置

当前头相机配置文件：

- /home/unitree/xr_teleoperate/teleop/teleimager/cam_config_server.yaml

当前关键参数：

- head_camera.type = opencv
- head_camera.image_shape = [480, 640]
- head_camera.binocular = false
- head_camera.fps = 30
- head_camera.video_id = 5  ← 注意：重启后可能变（原为4，现为5）
- head_camera.webrtc_port = 60001

> **⚠️ video_id 可能随重启变化！** 若启动失败报 `Cannot find OpenCVCamera`，运行
> `teleimager-server --cf` 查看当前实际 video_id，再修改配置文件：
> ```bash
> vim /home/unitree/xr_teleoperate/teleop/teleimager/cam_config_server.yaml
> ```

## 4. 启动 8012

### 4.1 启动命令

```bash
/home/unitree/miniconda3/bin/conda run -n tv python /home/unitree/xr_teleoperate/teleop/televuer/example/run_pico4u_8012.py --img-host 127.0.0.1 --public-ip 192.168.3.85
```

这个脚本会：

- 从本机 teleimager 读取头部图像
- 启动 televuer / vuer XR 页面
- 对 Pico4U 暴露 8012 页面地址

脚本路径：

- /home/unitree/xr_teleoperate/teleop/televuer/example/run_pico4u_8012.py

### 4.2 启动成功标志

启动后应可访问：

```text
https://192.168.3.85:8012/?ws=wss://192.168.3.85:8012
```

本机已验证该地址返回 HTTP 200。

### 4.3 如何停止

前台运行时：

```bash
Ctrl+C
```

后台运行时：

```bash
pkill -f run_pico4u_8012.py
```

### 4.4 后台启动方式

如果想用后台方式启动：

```bash
nohup /home/unitree/miniconda3/bin/conda run -n tv python /home/unitree/xr_teleoperate/teleop/televuer/example/run_pico4u_8012.py --img-host 127.0.0.1 --public-ip 192.168.3.85 >/tmp/run_pico4u_8012.log 2>&1 &
```

查看日志：

```bash
sed -n '1,120p' /tmp/run_pico4u_8012.log
```

## 6. 常见问题

### 6.1 为什么 60001 是平面的

因为 60001 本来就是相机预览页。

另外，当前头相机配置是单目：

- binocular: false

所以当前不是双目立体视图。

### 6.2 为什么 8012 也不是真双目沉浸

当前机器接的是内置单目 RealSense 彩色流，不是外接双目头相机。

因此：

- 60001 是单目预览
- 8012 是 XR 页面，但输入图像仍然来自单目相机

如果要真正双目沉浸，需要外接官方那类头部双目 RGB 相机，并把 head_camera 改成双目配置。

### 6.3 如果 8012 打不开，优先检查什么

先检查 60001 是否已经启动：

```bash
ss -ltn | grep ':60001'
```

再检查 8012 是否监听：

```bash
ss -ltn | grep ':8012'
```

再检查 8012 进程：

```bash
ps -ef | grep run_pico4u_8012.py | grep -v grep
```

### 6.4 证书放在哪里

当前证书路径：

- /home/unitree/.config/xr_teleoperate/cert.pem
- /home/unitree/.config/xr_teleoperate/key.pem

60001 和 8012 都会复用这套证书。
