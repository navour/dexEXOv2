模型方法与力学边界重视可验证性

几何闭环：以 MCP 为 (0,0)，人体三指骨按 θ₁、θ₂、θ₃ 计算 P；假设 Link 3 在指尖与远节方向一致，得 C=P−L₃u(φ)。再由 |AB|=L₁、|BC|=L₂ 的两圆交点求解 B，确保 Link 1/2/3 的关节位置和运动遵守刚体长度约束。

P = Σ pᵢ[cos(Σθⱼ), sin(Σθⱼ)] C = P − L₃[cos φ, sin φ] |B−A| = L₁, |C−B| = L₂ Q = A + AQ·u(α₁+β), d = |M−Q|

静力：电缸在 Q 点施加轴向力 Fd，Link 2 看作二力杆；利用 Link 1 关于 A 点力矩平衡求出 Link 2 内力 λ，再求 A/B/C 铰反力。指尖连接件因姿态耦合可以传递平面力与附加力偶，随后计算 MCP/PIP/DIP 反力与弯矩贡献。

τₐ = (Q−A) × Fmotor λ = −τₐ / ((B−A) × uBC) FB = λ·uBC, RA = −Fmotor−FB Ftip = −η·FB, Fn = Ftip·nφ τjoint = (P−J) × Ftip + Mtip

退化处理：两圆无交点、运动关系不单调、摇臂力臂接近零时提示不可求解或奇异。没有提供真实机构 CAD、全部销轴安装点与接触边界条件时，不声称输出等于原装置实验值。

文献可追溯性与假设说明源数据审计

论文直接给出的：五指 Link1/2/3 尺寸（Table 2）；食指 PP=50、MP=31、DP=21 mm 及角度范围（Table 3）；16 mm 行程；三连杆、末端魔术贴和底座球铰的构型描述（Figures 2/4）；力传递静力平衡路线（§2.3，Equations 7–10）；30 N 目标驱动力试验与 4 N 最大指尖反馈力报告（§4, Table 4）。

本网页增加的假设：输入到人体姿态的一维耦合曲线；A 和 M 的绝对坐标；摇臂 AQ 长度、偏置角 β；末端 Link 3 随远节方向刚性旋转；传递系数 η；电机轴转角与直线位移关系。以上没有论文定值，均可自行校准。

特别说明：论文并未披露电机的内部丝杠导程，也没有给出每个手指的铰点实测反力。本实验台展示的是根据论文结构建立的参数化可重复计算模型，而不是原作者 CAD 文件的精确动力学复刻。曲线中的 4 N 只是一条论文实验参考线，不用它反向硬调模型以制造一致结果。
